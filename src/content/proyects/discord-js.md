Es un pequeño proyecto en donde utilizo la api de discord ([Discord.js](https://discord.js.org/)).

En este se tenia planeado implementar un especie de mercado donde los usuarios podrían ver, comprar y vender bienes. Además de que podrían ganar dinero, tenerlo en 2 cuentas distintas (en la billetera o en el banco). Si el dinero lo tenias en la billetera, entonces otro usuario podría llegar a robarlo.

Todos los datos eran almacenados en la base de datos de Mysql.
Lamentablemente el proyecto quedó truncado cuando discord decidió cambiar su api y eso me demandaba rehacer todo el proyecto.
